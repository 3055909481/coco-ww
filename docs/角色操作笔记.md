# 原生角色操作笔记

原生角色代码(src/char/*.py)优化时整理的机制要点。来源: `E:\角色详细攻略` 里「打游戏的老二」的角色攻略视频
(字幕 OCR 稿在 `E:\角色详细攻略\_字幕稿`)、nanoka 技能页、做轴记忆。只记影响自动战斗怎么打的部分。

## 通用原则(所有原生角色)

- 原生代码要在任何状态下都能跑: 不知道角色是不是变身/强化态、有没有资源, 所以每一步先读屏判断, 读不到就按保底时长做完, 不能停在原地等。
- 每个循环都要有超时; 框架另有硬上限 `PERFORM_HARD_TIMEOUT`(默认 30 秒, 扣除时停), 到点松开按键强制切人。
- 长按一律用 `hold_mouse` / `hold_key` / `heavy_attack`(try/finally 保证松开)。
- 切人优先级别返回永久的 NO; 框架有防饿死(离场 40 秒抬到 NORMAL、70 秒压过 MUST), 辅助互切时主C离场超过 25 秒先回主C。这两条只在全队都是原生代码时生效。
- 自定义队伍代码继承原生类, 改原生类时方法名和参数不能变。
